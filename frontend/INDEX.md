## 🆘 Troubleshooting

### ZIP Download Empty?
→ Use GitHub method or copy files manually  
→ See **GET_STARTED.md**

### Installation Issues?
→ Check Node.js version: `node -v`  
→ Clear cache: `rm -rf node_modules && pnpm install`  
→ See **INSTALL.md**

### Dark Mode Not Working?
→ Clear browser cache  
→ Check theme toggle button  
→ See **THEME_GUIDE.md**

### Build Errors?
→ Run: `pnpm build --debug`  
→ Check TypeScript: `pnpm type-check`
